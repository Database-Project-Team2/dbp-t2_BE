# db/init 변경 기록

스키마(01_schema.sql)·시드(02_seed.sql)를 바꿀 때 이유를 남긴다. 프론트 `src/data/seed.json`도 같은 값으로 맞춘다.

## 2026-11-20 — 백엔드 연동 준비 (feat/integration)

- **비밀번호 해시 재생성**: 기존 `$2b$10$abcdefghijklmnopqrstuu…`는 `demo1234`와 일치하지 않았다(BCrypt 검사 실패). `./gradlew seedSecrets`로 `demo1234`의 BCrypt 해시를 새로 만들어 10명 모두에 적용했다. 비밀번호는 README·프론트 안내와 같은 `demo1234`.
- **주민번호 암호문 재생성**: 기존 값은 형식만 맞춘 자리표시자였다. 서버의 AES-256-GCM(`RESIDENT_NO_KEY`)으로 가상 주민번호 10개를 암호화해 교체했다. 번호는 프론트 `residentNumber.ts` 검사를 통과하는 가상 값이며 `src/test/java/.../tools/SeedSecrets.java`에 있다. 키가 다르면 응답의 마스킹 값이 `******-*******`로 표시된다.
- **학력 값 교체**: `대학교 졸업` → `대졸(학사)`. 프론트 학력 선택지(고졸/전문대졸(초대졸)/대졸(학사)/석사/박사)와 맞춘다. 서버 가입·프로필 수정 검사도 이 5개만 허용한다.

## 2026-11-20 — 시연용 샘플 데이터 보강 (feat/seed-sample-data)

- **평가 의견 다양화**: 34건 모두 같은 두 문장이던 의견을 점수에 맞는 서로 다른 문장으로 바꿨다. 점수·날짜·평가자 관계는 그대로다. 평가 상세·CSV 시연 시 행을 구분할 수 있게 하려는 목적이다.
- **직원 11 오지수(demo11) 추가**: 마케팅 직군, 2025-06-02 입사. 진행 중인 프로젝트 3에 투입일 없이 배정(member 24)만 되어 있어 "배정됐지만 투입 전" 상태와 2025년 다음 사번(20250007)을 보여 준다. 주민번호 암호문은 `./gradlew seedSecrets`로 11명 전체를 다시 만들었다(가상 번호는 `SeedSecrets.java`).
- **프로젝트 5 유통 사내 포털 개선 추가**: 2025-10-06 ~ 2025-12-19, 고객평가 의뢰·회수·보고까지 끝난 프로젝트. 구성원 박지훈(PM, member 21)·정도윤(PL, 22)·이서연(TESTER, 23), 평가 11건(35~45: 고객 3, PM 2, 동료 6). 일반 직원이 다른 프로젝트에서는 PM일 수 있는 경우와, 작년 경력·평가 이력을 보여 준다.
- **테스트 영향**: demo03이 프로젝트 5의 PM이 되어 "PM 이력 없는 일반 직원" 예시로 쓰던 테스트(BE·FE 단위·E2E)는 같은 조건(프로젝트 1·4 소속, 남은 동료평가 6건)인 demo04로 바꿨다. 건수 기대값은 새 시드에 맞췄다.
